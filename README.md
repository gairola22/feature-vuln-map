## 🏗️ Categories

### Features & Attack Surface
Application features mapped to their vulnerability types — from file uploads and auth flows to AI integrations and WebRTC.

### Attack Chains & Escalation
Proven chains that turn P4 bugs into P1 payouts — XSS→ATO, SSRF→cloud compromise, IDOR→mass breach.

### High-Value Targets
Where the $5K-$50K+ bugs live — auth systems, payment flows, data breach patterns, infrastructure access.

### Bypass & Advanced Techniques
WAF bypass, CSP evasion, HTTP/2 attacks, desync, parser confusion — exploit what others can't.

### Core Vulnerability Classes
Every fundamental injection and attack type — command injection, SSTI (all engines), deserialization (all formats), timing attacks.

### Technology Stack Testing
Framework-specific vulns — WordPress, React, Node.js, PHP, Java/Spring, Python, Ruby, .NET, AWS, Azure, GCP, Docker, Kubernetes.

### Bug Bounty Strategy
Target selection, recon automation, report writing, hunting patterns, toolchain — the meta-game.

## 📖 Usage

1. **Open the live page** or `index.html` locally
2. **Search** for the feature you're testing (e.g., "file upload", "OAuth")
3. **Expand** to see all vulnerability checks for that feature
4. **Test each check** against your target within authorized scope

## ⚠️ Disclaimer

This tool is for **authorized security testing only**. Always test within your program's scope and follow responsible disclosure practices.
